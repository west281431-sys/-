# FPV Assemble — фотодан «өзі құрастырылып жатқан» ролик

Пайдаланушы ұнатқан Инстаграм-видеоның (құрылыс алаңынан дрон ұшып, ғимарат өзі құрастырылатын 10 с ролик) әсерін **фотолардан** қайталайды.
Түпнұсқа 3D/AI-генератормен жасалған — оны дәл көшірмейміз. Әсерін аламыз: ұшқан камера, шаң бұлты, каркас, қабаттап құрастыру, ұшқын, жылдам ырғақ, соққы дыбыстары.

Пайдаланушы бағдарламашы емес. Қарапайым тілмен түсіндір, кодты сұрамаса көрсетпе. Әр кезеңнен кейін: «не жасадым» және «нені тексеру керек».

## Не керек
- Node.js 20+, ffmpeg, Google Chrome, Python 3 + numpy (дыбыс пен бит үшін).
- `npm install` (puppeteer-core) — шаблон папкасында бір рет.

## Қалай жасау керек (қадамдар)
1. **Жоба.** `template/` папкасын жаңа папкаға көшір (мысалы `жоба/кеме/`). `npm install`.
2. **Фотолар.** `media/photos/1.jpg … N.jpg` — ені 1080 px-ке кішірейт:
   `ffmpeg -i ФОТО -vf "scale=1080:-2" -q:v 3 media/photos/1.jpg`.
   Фотоларды өзің қарап шық: қайсысы жалпы план (финалға), қайсысы жақын (push), қайсысында объект анық әрі көлденең сызықтары көп (assemble-ге — каркасы әдемі шығады).
3. **Жоспар.** `video.html` ішіндегі `CONFIG.shots` — бір фото = бір сахна. Ережелер төменде. Жоспарды пайдаланушыға бір кестемен көрсет те, бірден жаса.
4. **Палитра.** `palette`: `dust` — құрылыс/жер, `spray` — теңіз/кеме/су, `smoke` — өрт/зауыт/ТЖ, `snow` — қыс. Каркас түсі: `wireColor: [255,255,255]`.
5. **Кадр-тексеру.** `node render.mjs stills 0.3 1.5 3 …` — әр сахнадан 1–2 кадр, бір параққа жинап, өзің қара (чек-лист төменде).
6. **Рендер.** `node render.mjs full` → `out/video.mp4` (кадрлар + барлық дыбыс эффектілері). 15 с ≈ 2–3 минут.
7. **Музыка.** Бит синтезде (лицензиясыз): `python3 -I ../scripts/beat.py ҰЗАҚТЫҒЫ media/beat.wav 112`
   (скилл папкасындағы `scripts/beat.py`). Араластыр:
   ```
   ffmpeg -i out/video.mp4 -i media/beat.wav -filter_complex "[1:a]atrim=0:D,volume=0.5,afade=t=in:d=0.2,afade=t=out:st=D-1.5:d=1.5[mu];[0:a][mu]amix=inputs=2:normalize=0:duration=first,loudnorm=I=-14:TP=-1.5[a]" -map 0:v -map "[a]" -c:v copy -c:a aac -b:a 192k out/final.mp4
   ```
   (D — ролик ұзақтығы.) Дауыс болса (`media/voice.m4a`), битті дауыс астында басу үшін `sidechaincompress` қос (Nurserik Studio Hook-тағы команда).
8. **Дайын файл** — `out/final.mp4`, түсінікті атпен пайдаланушыға жібер.

## CONFIG — сахна түрлері
```js
{ src: 'media/photos/3.jpg', kind: 'assemble', dur: 2.8, strips: 6, sparks: 0.55 }
```
| kind | Не болады | Ұзақтығы |
|---|---|---|
| `rise` | Камера төменнен жоғары көтеріліп ұшады (дрон жерден ұшқандай) | 1.4–1.8 с |
| `push` | Алға жылдам ұшу, сәл айналу | 1.0–1.4 с |
| `orbit` | Объектіні бүйірден айналып өту | 1.2–1.6 с |
| `assemble` | Бұлыңғыр бос алаң → ақ каркас төменнен өседі → фото `strips` қабатқа бөлініп, төменнен жоғары қарай бір-бірден жоғарыдан түседі (әрқайсысы — соққы, діріл, шаң) | 2.4–3.2 с |
| `pan` | **Баяу панорама**: камера фотоның бір нүктесінен екіншісіне асықпай өтеді — жазуды, нөмірді, логотипті оқытып көрсетуге. `from: [x, y, zoom]`, `to: [x, y, zoom]` (x, y — фотодағы орны 0…1, zoom ≈ 1.0–1.8). Жұмсақ кинематографиялық дыбыс. Көлденең фотоға өте жақсы | 2.6–3.4 с |
| `final` | Камера баяу артқа шегінеді, тақырып шығады, соңында қараңғыға кетеді | 2.0–2.8 с |

Қосымша өрістер: `sparks: 0.55` (ұшқын сахнаның қай бөлігінде), `sparkX/sparkY` (0–1, экрандағы орны), `burst: false` (бұл өтпеде шаң болмасын), `burstPower: 1.3`, `title`, `sub`, `titleAt`, `titleY`, `titleSize`, `move: 'push'|'rise'|'orbit'|'pull'` (камераны ауыстыру).
Глобал: `transition` (өтпенің жартысы, әдепкі 0.22), `fadeOut: false`, `sound: { whoosh, burst, thud, impact, clank, spark, title, final }` — қаттылықтар.

## Жақсы шығатын жоспар (6–7 фото)
`rise → push → assemble → orbit → push → assemble → final`
- Ырғақ жылдам: жалпы 12–16 с. Ұзақ сахна — тек `assemble` пен `final`.
- `assemble` — 1–2 рет, ең әдемі, объект анық көрінетін фотоға. Ұшқын (`sparks`) — бір рет, металл/дәнекер тақырыбына.
- Бірінші сахна `rise` — хук: шаң бұлтынан камера ұшып шығады.
- Соңғы — ең жалпы, «дайын» фото, `final` + тақырып (қазақша, 1–3 сөз, капс емес, Inter 800).
- Теңіз/кеме: `palette: 'spray'`, `strips: 5–7` (кеме қабаттары, палуба), `sparks` — кеме жөндеу/дәнекер фотосына.
- Жазу/нөмір көрсету керек болса (мысалы кемедегі «112», атауы) — `pan`: жазудың бір шетінен екінші шетіне, `burst: false` (жазу шаңмен жабылмасын). Координатаны фотоны қарап өзің тап.
- ТЖ/ғимараттар: `palette: 'smoke'` не `'dust'`, әр ғимаратқа бір `assemble` (2.4 с) — «тарс-тарс шығады».


## SAIL — объект теңізде жүзеді, камера айналып ұшады (ЕҢ ДИНАМИКАЛЫҚ)
Пайдаланушы «жылдам, FPV сияқты айналып ұшсын, кеме теңізде жүзсін» десе — осы режим. Кеме, қайық, көлік, ұшақ — фоннан бөлінетін кез келген объект.
1. **Бөлу:** `python3 -I ../scripts/cutout.py media/photos/a.jpg media/photos/b.jpg:0 …`
   (бірінші рет: `pip install rembg onnxruntime`, модель ~180 МБ жүктеледі). Әр фотодан `_obj.png` (объект) + `_bg.jpg` (объектісіз фон: аспан сол қалпы, теңіз таза су жолағынан қайта құрастырылады).
   `ФАЙЛ:0` — көкжиек жоқ (үстінен түсірілген кадр), `ФАЙЛ:0.35` — көкжиек биіктігі қолмен.
   `_bg.jpg`-лерді бір параққа жинап қара: жолақ/көбік қайталанса — сол кадрға ұқсас жарықтағы басқа фотоның фонын бер (`bg: 'media/photos/x_bg.jpg'`).
2. **Сахна:**
```js
{ src: 'media/photos/a.jpg', kind: 'sail', move: 'orbitL', dur: 1.5, heading: [1, 0], speed: 360,
  stern: [.18, .76], bow: [.88, .74], whip: 1 }
```
| өріс | мәні |
|---|---|
| `move` | `orbitL` / `orbitR` — айналып ұшу (кеме ортада, фон қарсы жаққа жылдам жылжиды), `pass` — жанынан зулап өту, `chase` — артынан/алдынан қуып жақындау, `dive` — жоғарыдан құлап түсу, `rise`, `pull` — финалға артқа шегіну |
| `heading` | кеменің экрандағы жүру бағыты `[x, y]` (оңға `[1,0]`, солға `[-1,0]`, камераға `[0,.25]`, камерадан `[0,-.25]`) — су осыған қарсы ағады |
| `speed` | су ағысы, px/с (300–400 жылдам) |
| `stern` / `bow` / `bow2` | фотодағы арт / тұмсық нүктелері (0…1) — көбік ізі және шашыранды осыдан шығады |
| `shipW` | кеменің ені экранның қанша бөлігі (әдепкі .9; алдынан/артынан кадр .5, алыстағы кеме .1) |
| `shipY` | кеменің ортасы экранның қай биіктігінде (әдепкі .56) |
| `whip` | свайп-өтпе бағыты `1` / `-1` — айналу бағытына сай кезектестір |
| `bg`, `foamSize`, `zoomFlow`, `waterline`, `waterFoam: false` | қосымша |
3. **Айналып ұшу сезімі** үшін ракурстарды кеменің айналасы бойымен ретте: бүйір → 3/4 алды → алды → екінші бүйір → үсті → арты. Әр сахна 1.2–1.6 с, өтпе `transition: 0.16`, бит 128 BPM.
4. Дыбыс өзі қойылады: әр сахнаға су шашырауы, ортасында «вжух» (жанынан ұшып өту), өтпеде whoosh.

Үлгі жоба: «Теңіз жасағы 112» — 9 фото, 13.7 с: `dive → pass → orbitL → chase → orbitR → pass → pass(күн бату) → chase(арты) → pull + «Теңіз жасағы / 112»`.

## Дыбыстар (автомат)
| Сәт | Дыбыс |
|---|---|
| Әр өтпе | `whoosh` + `rumble` (шаң) / `splash` (spray) |
| Әр қабат түскенде | `thud` + `clank` (металл) |
| Соңғы қабат | `impact` (ауыр соққы) |
| Ұшқын | `spark` |
| Тақырып | `thud` |
| Финал | `boom` |
`clank`, `spark`, `rumble`, `splash`, `impact` — `scripts/sfx.py` синтездеген, лицензиясыз. Қайта жасау: `python3 -I scripts/sfx.py template/a/sfx`.

## Ережелер
1. Фотоларды бұрма, бөтен суреттерді (логотип, біреудің контенті) қоспа — тек пайдаланушы берген фотолар.
2. Мәтін аз: тек финалда (немесе бір хук сөзі). Бұл — көрініс роликі, оқитын ролик емес.
3. Әр соққы — көзге көрінетін оқиға (қабат түсті, өтпе болды). Бос дыбыс қойма.
4. Шаң экранды толық жапса — 0.3 с-тан аспасын (`burstPower` ≤ 1.4).
5. Бит дауыссыз роликте ~ -18…-20 LUFS деңгейінде, дыбыс эффектілерін басып кетпесін.
6. Көлденең фотолар да болады (cover-fit), бірақ тік фото әдемірек.

## Чек-лист (рендер алдында)
- [ ] Каркас сызықтары көрінеді (қараңғы фонда ақ), объект танылады.
- [ ] Қабаттар төменнен жоғары ретпен түседі, соңғысы күштірек соғылады.
- [ ] Өтпелерде шаң бұлты жұмсақ (дөңгелек «дақтар» көрінбейді).
- [ ] Тақырып экраннан шықпайды, шрифт Inter (серифті емес).
- [ ] Ролик соңы қараңғыға жұмсақ кетеді.

## Жиі мәселелер
- **Сурет табылмады** — `src` жолын тексер (`media/photos/…`), кеңейтімі `.jpg`.
- **Каркас әлсіз** — фото тым бұлыңғыр/қараңғы; басқа фото таңда немесе `assemble`-ді `push`-қа ауыстыр.
- **Рендер үзілді** — `RESUME=1 node render.mjs full`.
- **Шрифт серифті** — `a/Inter.ttf` орнында екенін тексер.
