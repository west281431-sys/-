# FPV Assemble скиллын орнату

## Claude Code (компьютерде)
1. `fpv-assemble.zip` ашыңыз (распаковать).
2. `fpv-assemble` папкасын мына жерге көшіріңіз:
   - Windows: `C:\Users\<сіздің атыңыз>\.claude\skills\fpv-assemble`
   - Mac: `~/.claude/skills/fpv-assemble`
3. Claude Code-ты қайта ашыңыз. Енді «fpv-assemble скилімен мына фотолардан видео жаса» десеңіз болғаны.

## Claude.ai (сайт/қосымша)
Settings → Capabilities → Skills → «Upload skill» → `fpv-assemble.zip` таңдаңыз.

## Қажетті бағдарламалар (компьютерде бір рет)
Node.js 20+, ffmpeg, Google Chrome, Python 3 + numpy. Claude өзі тексеріп, жетіспесе айтады.

## Қалай қолдану
Фотоларды (6–10 дана) бір бумаға салып, Claude-қа: «fpv-assemble: теңіз, кеме, соңында "ТЕҢІЗ ФЛОТЫ" деп жаз» деңіз.
